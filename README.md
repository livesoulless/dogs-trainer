# Воспитание собаки

Карманный гид по воспитанию собаки: этапы от первого дня дома до взрослой собаки, команды с пошаговой анимацией, программа прогулок без поводка, жизнь с двумя собаками, сон, одиночество дома, лакомства, погрызенные вещи, течка и стерилизация. При первом запуске приложение спрашивает кличку, пол и возраст собаки (и второй, если она есть) и подстраивает советы.

Это одна HTML-страница без сборки и сервера. Прогресс хранится в браузере на устройстве.

## Как открыть на iPhone

### 1. Сделайте репозиторий публичным

На бесплатном аккаунте GitHub Pages работает только для публичных репозиториев.

1. Откройте https://github.com/livesoulless/dogs-trainer
2. Вкладка **Settings** (шестерёнка в верхнем меню репозитория, не в меню профиля).
3. Внизу страницы **General**, блок **Danger Zone** → **Change visibility** → **Make public** → подтвердите.

### 2. Включите GitHub Pages

1. Там же, в **Settings** репозитория, слева выберите **Pages**.
2. **Build and deployment → Source:** «Deploy from a branch».
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты вверху появится адрес `https://livesoulless.github.io/dogs-trainer/`.

Если видите страницу с кнопкой **Add a domain** — это настройки профиля (github.com/settings/pages), а не репозитория. Домен добавлять не нужно.

### 3. Установите на телефон

Откройте адрес в Safari → «Поделиться» → «На экран “Домой”» → «Добавить».
