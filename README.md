# Воспитание собаки

Карманный гид по воспитанию Полли: этапы от первого дня дома до взрослой собаки, команды с пошаговой анимацией и программа прогулок без поводка.

Это одна HTML-страница без сборки и сервера. Прогресс хранится в браузере на устройстве.

## Как открыть на iPhone

1. Включите GitHub Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Через минуту сайт будет по адресу `https://livesoulless.github.io/dogs-trainer/`.
3. Откройте его в Safari → «Поделиться» → «На экран “Домой”».

Приложение запустится на весь экран, как обычное.

## Файлы

- `index.html` — всё приложение
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-*.png` — иконка и настройки для экрана «Домой»
